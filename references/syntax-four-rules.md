# 四大句法规则：祈使句 · 不是而是 · 无灵主语 · 逗号链

PPT 文案的"机器腔"主要集中在句法层，不在词汇层。以下四规则是 ppt-deai 的核心手术刀。每条给出：识别 → 改法 → Before/After。

---

## 规则一：减少祈使句

### 为什么

AI 生成 PPT 时偏爱短促的命令式标题，因为祈使句"有力"。有力过头就是口号。真人做的分享 PPT，标题以**陈述句、判断句、设问句**为主。祈使句是稀缺资源，全份最多一个，通常留给结尾。

### 识别

- 动词开头的标题："把想法，做成作品""先做一个能用的东西""去报名。然后做完。"
- 隐性祈使（"要 / 得 / 应该"开头）："要先核对规则，再打磨创意""一定要走出实验室"。
- 口号式三连祈使："去报名，然后做完。"（两个动词短语连发）

### 改法

| 原句型 | 改后句型 | 示例 |
|---|---|---|
| 祈使口号 | 陈述判断 | "把想法，做成作品" → "想法和作品之间，隔着几百个小时" |
| 祈使口号 | 设问 | "先做一个能用的东西" → "第一版要多粗糙，才能开始？" |
| 动作命令 | 具体动作 + 主语 | "删掉所有回答不了它们的页面" → "项目书里回答不了这三个问题的页，删掉" |
| 隐性祈使 | 条件判断 | "一定要走出实验室" → "调研这事，待在宿舍里做不出来" |

### 配额

- 祈使句标题全稿 ≤1 处，放在结尾页当签名。
- "先 X，再 Y"句式全稿 ≤2 处。它同时是 AI 对仗癖，见 ppt-ai-patterns B2。

## 规则二：多用"不是 A，而是 B"

### 为什么

平铺并列（"问题真不真、是不是你做的、能长多大"）是 AI 的默认陈列方式。"不是 A，而是 B"把对比和判断**显式化**，读者能看见你在掂量。这是"背后有人"的最直接信号。

它也顺手治两种病：替代祈使句（命令变判断），替代无灵主语（抽象主语句变对比结构）。

### 与"不仅…更是…"的区别（重要）

- 要用："淘汰人的**不是**创意不够好，**而是**报名表填错了"。对比、纠偏、具体。
- 禁用："这不仅是一次更新，**更是**一次革命"。拔高排比，humanizer-zh-pro 规则 9 明令清除。

判据：**"不是"后面跟着一个被推翻的预期，"而是"后面跟着真相**。没有推翻感的都不是合格的"不是而是"。

### 配额与防套路

- 每页 ≤1 处，全文 ≤4 处。超过就成新的 AI 模板。
- 不要在连续两页使用同一句式变体。

### Before/After

| 改前 | 改后 |
|---|---|
| 规则比创意更早淘汰人。 | 淘汰人的从来不是创意不够好，而是报名表填错了。 |
| 完美主义是备赛最大的敌人。 | 拖住你的不是能力不够，是总想等准备好了再开始。 |
| 校赛评委是老师，总决赛有投资人。 | 校赛台上坐的不是投资人，是校内老师。到了总决赛，提问的才换成企业专家。 |
| 比赛看的是落地能力。 | 创新大赛看的不是点子新不新，而是它能不能落地、能不能长成一门生意。 |

## 规则三：少用无灵主语

### 为什么

无灵主语（inanimate subject）＝让抽象事物发出只有人才有的动作："规则**淘汰人**""比赛**逼着你**""报名**会给你**一个进度条""完美主义**是敌人**"。

LLM 偏爱它，因为抽象主语最安全、最普适。真人写东西，主语大多是人、团队、评委、学校这类有灵主语，或是"台上 / 台下 / 表里"这类具体空间。

### 识别

扫描"抽象名词 + 人类动词"组合：

- 淘汰人 / 逼着 / 会给你 / 送你 / 是……的敌人 / 决定 / 意味着 / 见证了 / 标志着
- 常见抽象主语词：规则、比赛、时间、完美主义、报名、进度条、课堂、简历、评委席、舞台

### 改法（按优先级）

1. **换成有灵主语**："三级赛制逼着你把半成品迭代成能演示的版本" → "校赛省赛总决赛一场场比下来，每一轮评委都能挑出新问题，你只能一轮轮改"。
2. **换成存在句 / 空间句**："课堂上给不了这三样东西" → "有三样东西，课堂给不了"。
3. **换成条件句**："报名只需要十分钟" → "报名表十分钟就能填完"。
4. **隐喻句降级**：实在想保留，把动作主语改成被观察的物件："它会给你一个学期都还不完的进度条" → "填完那一刻，一个进度条就开始跑了，一个学期都关不掉"。

### 配额与例外

- 谚语式无灵主语（"规则比创意更早淘汰人"）**全稿仅留 1–2 处**。这种句子有格言感，是签名级表达。留三处以上就成 AI 复发。
- 数据页的"数字 + 说明"不算无灵主语病变（"300 万名学生参赛"是正常陈述），不要误伤。

## 规则四：拆逗号链（一逗到底）

### 为什么

AI 写中文有个顽固习惯：一句里塞四五个分句，逗号一路串到底，该用句号的地方也懒得断。读起来一口气上不来，像有人不停顿地念稿。

真人写东西，句号用得很果断。一个句子只说一个意思。句子短，判断才显得硬。

### 识别

数两个句号之间的逗号：

- **≥3 个逗号即高危，拆。**
- 开头一串状语："随着 X 的不断深入，在 Y 的大背景下，Z……"
- 从句套从句："当 A 的时候，如果 B，那么 C，所以 D。"
- 长主语拖尾："这个由三人组成、来自不同专业、利用课余时间完成的项目……"

### 改法四招

| 招 | 做法 | 示例 |
|---|---|---|
| 1. 切短句 | 一个分句一个句号 | "随着赛事的不断推进，各高校参与热情持续高涨，报名人数逐年攀升，竞争愈发激烈。" → "赛事一年年办下来，报名的人越来越多。竞争越来越激烈。" |
| 2. 删状语 | "随着……的不断发展"整段删掉，不伤句子 | "在时间紧、任务重、资源有限的情况下，团队依然按时完成了原型开发。" → "时间紧，人手也不够。团队还是按时把原型做了出来。" |
| 3. 状语后置 | 先说什么在发展，再说跟着变什么 | "随着 X 的发展，Y 变了" → "X 发展得快。Y 也跟着变了。" |
| 4. 长主语拆出 | 把修饰语拆成独立短句 | "这个由三人组成、来自不同专业、利用课余时间完成的项目获得了金奖。" → "项目是三个人做的。他们来自不同专业，用的都是课余时间。项目拿了金奖。" |

### 配额

- 标题：最多 1 个逗号。标题是拿来扫的，不是拿来读的。
- 正文：一句最多 2 个逗号。超过就拆。
- 全文 ≥3 逗号的句子清零。脚本 B7 自动数，改完重跑确认。

## 四规则的协同顺序

一段文本同时中四病时，按此顺序手术：

1. **先拆无灵主语**，找到"谁在做"。主语一明确，句子骨架就正了。
2. **再把祈使句改判断 / 设问**，去掉口号腔。
3. **拆逗号链**，长句切短，句号果断。
4. **最后在关键处点一处"不是 A，而是 B"**，让判断显式化。一句就够，别贪。

示例（同一句的四步）：

> 原句：先做一个能用的东西。（祈使句）
> 第一步（拆无灵主语）：先做一个你自己能当场跑起来的东西。（主语"你"浮现）
> 第二步（改判断）：评委要的不是完美的设想。
> 第三步（拆逗号链，备用）：评委要的不是完美的设想，而是一个你能当场跑起来、经得起追问的东西。
> 第四步（点对比）：评委要的不是完美的设想，而是一个你能当场跑起来的东西。
