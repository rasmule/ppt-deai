# 严格模式附加规则（规则六–十一 · 多轮实战沉淀）

标准五规则见 `references/syntax-five-rules.md`，模式库与扣分见 `references/ppt-ai-patterns.md`。本文件是**第二层**：用户逐轮点名、配额一路收紧时的严格模式。

来源：2026-10「历代名将与国家军事理论」PPT 七轮去 AI 味实战。用户七轮反馈分别是：比喻与「先X再Y」→ 用词太猛脱离日常语言 → 「只就才也是」→ 指示词 → 时空指示词与标题配平 → 「没/不是」。每轮只解决一类，分数 66 → 93。以下是沉淀。

## 什么时候进严格模式

- 用户说"还有 AI 味"但不再点名 → 按本文件全清单过一遍；
- 用户点名具体类别（"减少比喻""把'今天'去掉"）→ 只对该类别清零，其余不动；
- **每轮只改锁定的类别**。不顺手改别的——改多了说不清是哪轮起效，回归时也说不清是哪轮改坏的。

## 规则六：零比喻

### 为什么

物理比喻（柱子、秤、押、磨、下沉）把抽象关系"演"给读者看，是人类作者也用的手法，但 AI 用得又密又工整，一页能凑出三四个。用户对这类改写的原话是：**"用词的度太猛，脱离日常语言。"**

### 清单（命中即换，严格模式全稿 0）

柱子、支柱、四梁八柱、梁柱、秤、垫（脚石）、压（舱石）、磨、下沉、押（注）、托举、撬动、撑起、定海神针。

技术搭配除外：「压缩」「打磨」「抵押」等有专门义的词是人说的，不是比喻，需人工确认后留。

### 改法

比喻改直陈，说关系本身。

| 改前 | 改后 |
|---|---|
| 国家军事理论是四根支柱 | 军事理论讲四条 |
| 把胜负押在某一场会战上 | 胜负全看某一场会战 |
| 理论越往后越下沉 | 理论越往后越细 |

### 配额

严格模式全稿 0。标准模式 ≤2 处且不在同一页。

## 规则七：语域降级（去猛词）

### 为什么

去 AI 味最常见的失败：把一个 AI 套话换成**另一个书面猛词**。味没去掉，只是换了个更浓烈的写法。用户原话："用词的度太猛，脱离日常语言。"

### 判断标准：朗读测试

这个词会出现在日常聊天里吗？不会，就降一级。去味词的语域**不能高于**被换掉的词。

| 书面猛词 | 日常说法 |
|---|---|
| 至关重要 | 要紧、事关重大 |
| 不可不察 | 得看清楚、不能不掂量 |
| 成形的军事理论 | 现成的军事理论 |
| 赋予……以使命 | 让……担起…… |
| 纵观两千年 | 两千年看下来 |

### 配额

严格模式全稿猛词 0。改完通读一遍，凡是"朗诵腔"的地方再降一级。

## 规则八：功能词极简

### 为什么

只、就、才、也、是——五个高频功能词，AI 拿它们垫语气。删掉之后句子意思不变，但语气会松掉、像人话了。

### 改法

- 只/就/才/也：删掉不伤句子的全删。「就是」「也在」「才有」等固定搭配可留。
- 是：只留在「是……的」强调框里，全稿 ≤3 处（本系列终稿留 P04「讲的是打不打」、P12「图的是全局」、P16「靠的是体系」三处）。其余「是」改「＝」式直陈或删。

### 配额

严格模式：只/就/才/也全稿 0；是 ≤3 处强调框。

## 规则九：指示词与时空指示词清零

### 为什么

这、那、各有各的、今天、从此——指示词把读者摁进作者当时的场域，是演讲稿腔的标配；「今天」还把内容钉死在一个日期上，过时最快。

### 改法

| 改前 | 改后 |
|---|---|
| 这套理论用了两千年 | 《孙子》用两千年 |
| 六位名将各有各的路子 | 六位名将，路子一个是一个 |
| 今天的打法 | 眼下的打法 / 现在的打法 |
| 从此岳家军成了神话 | 之后岳家军成了神话 |

### 配额

严格模式全稿 0。

## 规则十：作者话否定词清零（引文豁免）

### 为什么

作者话里堆否定词＝不停划界限而不给判断，是 AI 的安全癖。"不是天才，是体系的产物"绕一圈，不如直接说判断。

### 豁免

古籍引文、字源字义、专有名词里的否定词**不动**：「不可不察也」「止戈为武」「不战而屈人之兵」照原文留。扫描器命中引文内否定词属误报，以保留清单为准。

### 配额

严格模式：作者话中「没」「不是」（连带「不」）全稿 0，引文除外。

## 规则十一：双行标题配平

### 适用

标题用 ` / `（两侧带空格）分行的版式——eink-deck 的 h_hero / h_xl 字段即此语法。渲染时两侧各占一行，字数差太大视觉上头重脚轻。

### 五条原则

1. 两侧字数尽量配平，差 ≤2 字；
2. **只挪字，不加字**（去 AI 味在 PPT 里靠删和换，不靠加）；
3. 总字数只减不增；
4. 不回收禁用词（不能为了配平把「这」「今天」挪回来）；
5. 不破坏语义断点（不在一个词中间劈开）。

### 示例

| 改前 | 改后 |
|---|---|
| 兵将武 / 三个字一部观念史（3 / 8） | 兵将武三字 / 字里藏着仗（5 / 6） |
| 以少胜多 / 弱势方出兵几何（4 / 7） | 以少胜多战例 / 人少出多少兵（6 / 6） |
| 战略战役战术 / 三层各有其人（6 / 6，已平但含 B1「三层」+ C3「各有」） | 庙算、决战、白刃 / 三种打法不一样（7 / 7，先过模式关再配平） |

注意顺序：**先过模式关（B/C 类），再配平**。为了配平把禁用词挪回来是倒挂。

## 多轮迭代工作流（每轮闭环）

1. **锁定类别**：用户点名，或从上轮扫描报告的 Top 扣分里挑一类；
2. **改**：只改锁定类别，按规则六–十一手术；
3. **同步扫描留档**：每版存一份 `P<页码>\t` 文本，历史版本留档**不覆盖**（改动前/改动后/混合版各一份）；
4. **重跑扫描器**：标准模式 `scan_ppt_ai.py 留档.txt`；严格模式加 `--strict`（追加 C1–C5 实战配额检查）。**分数必须不降**——下降说明本轮改出了新的模式（实战教训：某轮拆句拆出三逗号链，93→90，回退重改才恢复）；
5. **交付本轮明细**：Before→After + 命中规则，追加进总报告，写进工作日志。

## 保留清单机制

每轮明确记录"有意保留"项。两个作用：防止下轮把上轮特意留住的东西又"修"掉；扫描器命中保留项时不当漏网。

典型保留项：

- **史料引文**（B7 逗号链豁免：《孙子》"兵者，国之大事，死生之地，存亡之道，不可不察也"四逗号句）
- **数据与出处注**（兵力数字、年份、'古代数字多含夸张成分'类免责注）
- **系列名回环**（封面与结尾页重复出现系列名，B5 豁免）
- **签名句**（「是……的」强调框 ≤3 处）

本系列终稿的保留清单即按此记录，七轮里没有再被误伤。
