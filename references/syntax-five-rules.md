# 五大句法规则：祈使句 · 关联词 · 无灵主语 · 逗号链 · 修辞癖

PPT 文案的"机器腔"主要集中在句法层，不在词汇层。以下五规则是 ppt-deai 的核心手术刀。每条给出：识别 → 改法 → Before/After。

---

## 规则一：减少祈使句

### 为什么

AI 生成 PPT 时偏爱短促的命令式标题，因为祈使句"有力"。有力过头就是口号。真人做的分享 PPT，标题以**陈述句、判断句**为主。祈使句是稀缺资源，全份最多一个，通常留给结尾。

### 识别

- 动词开头的标题："把想法，做成作品""先做一个能用的东西""去报名。然后做完。"
- 隐性祈使（"要 / 得 / 应该"开头）："要先核对规则，再打磨创意""一定要走出实验室"。
- 口号式三连祈使："去报名，然后做完。"（两个动词短语连发）

### 改法

| 原句型 | 改后句型 | 示例 |
|---|---|---|
| 祈使口号 | 陈述判断 | "把想法，做成作品" → "想法和作品之间，隔着几百个小时" |
| 祈使口号 | 条件判断 | "先做一个能用的东西" → "第一版要做多糙，才能见人" |
| 动作命令 | 具体动作 + 主语 | "删掉所有回答不了它们的页面" → "项目书里回答不了这三个问题的页，删掉" |
| 隐性祈使 | 条件判断 | "一定要走出实验室" → "调研这事，待在宿舍里做不出来" |

注意：替代方案里**没有设问句**。设问同样是 AI 的修辞癖，见规则五。

### 配额

- 祈使句标题全稿 ≤1 处，放在结尾页当签名。
- "先 X，再 Y"句式全稿 ≤2 处。它同时是 AI 对仗癖，见 ppt-ai-patterns B2。

## 规则二：少用"不是 A，而是 B"等关联词

### 为什么

"不是 A，而是 B"曾是去 AI 味的工具。它把对比判断显式化，读者能看见你在掂量。问题是 AI 学得太快，现在满屏都是"淘汰你的不是能力，是勇气""重要的不是速度，是方向"。用三处以上，它就从"背后有人"的信号变成了新的机器腔。

其他同类关联词一并限额："不仅…更是…""既…又…""一方面…另一方面""与其…不如…"。它们都在用形式上的周全代替判断。

### 识别

- 对比转折关联词："不是…而是…""与其…不如…"
- 并列拔高关联词："不仅…还…""既…又…""一方面…另一方面"
- 隐性关联："关键在于""说到底""本质上"（一段里出现两次以上就是在搭结构）

### 改法

判断直接陈述，不用关联词搭架子。

| 改前 | 改后 |
|---|---|
| 淘汰人的从来不是创意不够好，而是报名表填错了。 | 创意不够好，很少淘汰人。报名表填错，直接出局。 |
| 这不仅是一次更新，更是一次重构。 | 这是一次重构，改的是底层数据结构。 |
| 与其追求完美，不如先做出来。 | 先做出来。完美是改出来的。 |
| 拖住你的不是能力不够，是总想等准备好了再开始。 | 能力都够。拖住你的是"再准备准备"这句话。 |

### 配额

- 全部关联词合计全稿 ≤2 处。
- 不要在连续两页使用同一句式变体。
- 禁用"不仅…更是…"式拔高排比。humanizer-zh-pro 规则 9 明令清除。

## 规则三：少用无灵主语

### 为什么

无灵主语（inanimate subject）＝让抽象事物发出只有人才有的动作："规则**淘汰人**""比赛**逼着你**""报名**会给你**一个进度条""完美主义**是敌人**"。

LLM 偏爱它，因为抽象主语最安全、最普适。真人写东西，主语大多是人、团队、评委、学校这类有灵主语，或是"台上 / 台下 / 表里"这类具体空间。

### 识别

扫描"抽象名词 + 人类动词"组合：

- 淘汰人 / 逼着 / 会给你 / 送你 / 是……的敌人 / 决定 / 意味着 / 见证了 / 标志着
- 常见抽象主语词：规则、比赛、时间、完美主义、报名、进度条、课堂、简历、评委席、舞台

### 改法（按优先级）

1. **换成有灵主语**："三级赛制逼着你把半成品迭代成能演示的版本" → "校赛省赛总决赛一场场比下来，每一轮评委都能挑出新问题，你只能一轮轮改"。
2. **换成存在句 / 空间句**："课堂上给不了这三样东西" → "有三样东西，课堂给不了"。
3. **换成条件句**："报名只需要十分钟" → "报名表十分钟就能填完"。
4. **隐喻句降级**：实在想保留，把动作主语改成被观察的物件："它会给你一个学期都还不完的进度条" → "填完那一刻，一个进度条就开始跑了，一个学期都关不掉"。

### 配额与例外

- 谚语式无灵主语（"规则比创意更早淘汰人"）**全稿仅留 1–2 处**。这种句子有格言感，是签名级表达。留三处以上就成 AI 复发。
- 数据页的"数字 + 说明"不算无灵主语病变（"300 万名学生参赛"是正常陈述），不要误伤。

## 规则四：拆逗号链（一逗到底）

### 为什么

AI 写中文有个顽固习惯：一句里塞四五个分句，逗号一路串到底，该用句号的地方也懒得断。读起来一口气上不来，像有人不停顿地念稿。

真人写东西，句号用得很果断。一个句子只说一个意思。句子短，判断才显得硬。

### 识别

数两个句号之间的逗号：

- **≥3 个逗号即高危，拆。**
- 开头一串状语："随着 X 的不断深入，在 Y 的大背景下，Z……"
- 从句套从句："当 A 的时候，如果 B，那么 C，所以 D。"
- 长主语拖尾："这个由三人组成、来自不同专业、利用课余时间完成的项目……"

### 改法四招

| 招 | 做法 | 示例 |
|---|---|---|
| 1. 切短句 | 一个分句一个句号 | "随着赛事的不断推进，各高校参与热情持续高涨，报名人数逐年攀升，竞争愈发激烈。" → "赛事一年年办下来，报名的人越来越多。竞争越来越激烈。" |
| 2. 删状语 | "随着……的不断发展"整段删掉，不伤句子 | "在时间紧、任务重、资源有限的情况下，团队依然按时完成了原型开发。" → "时间紧，人手也不够。团队还是按时把原型做了出来。" |
| 3. 状语后置 | 先说什么在发展，再说跟着变什么 | "随着 X 的发展，Y 变了" → "X 发展得快。Y 也跟着变了。" |
| 4. 长主语拆出 | 把修饰语拆成独立短句 | "这个由三人组成、来自不同专业、利用课余时间完成的项目获得了金奖。" → "项目是三个人做的。他们来自不同专业，用的都是课余时间。项目拿了金奖。" |

### 配额

- 标题：最多 1 个逗号。标题是拿来扫的，不是拿来读的。
- 正文：一句最多 2 个逗号。超过就拆。
- 全文 ≥3 逗号的句子清零。脚本 B7 自动数，改完重跑确认。

## 规则五：少设问、少感叹、减骈偶

### 为什么

设问、感叹、骈偶是三种"表演型句式"。AI 用它们制造现场感，结果全是演的。PPT 是拿来扫的，不是拿来朗诵的。判断直接给出来，读者自己会掂量。

三种句式各自的问题：

- **设问句**。用疑问句式掩盖没有立场。"什么才是好的创意？"问完不给答案，或者给一个万金油答案。真人有观点就直接说。
- **感叹号**。语气放大器。"这太重要了！"感叹号替读者激动，读者无感。AI 标题带感叹号的比例远高于人类。
- **骈偶**。两句字数相等、词性相对，读起来像对联。"字斟句酌，反复推敲""始于兴趣，成于坚持"。它对仗的工整，是以信息密度为代价的。

### 识别

- 设问：以"吗 / 呢 / 什么 / 为什么 / 如何"收尾的问句；自问自答也算。
- 感叹：任何"！""！！""!!"。
- 骈偶：相邻两句字数相同或接近（差 ≤2 字），结构平行（"有 X，有 Y，有 Z"既是对仗也是排比三连，见 A3）。

### 改法

| 原句式 | 改后 |
|---|---|
| 设问 | 直接陈述或判断。"什么是好的创意？" → "好创意的标准只有一个：能落地。" |
| 自问自答 | 只留答案。"时间从哪来？从晚上和周末来。" → "时间从晚上和周末里抠。" |
| 感叹句 | 陈述句，删感叹号。"这改变了整个赛道的格局！" → "赛道的评判标准换了。去年的打法今年不灵了。" |
| 感叹收尾 | 戛然而止的短句。"让我们拭目以待！" → "明年三月，见分晓。" |
| 骈偶整句 | 拆成长短不齐的两句，信息拉开。"字斟句酌，反复推敲。" → "稿子改了十一版。每一版都念出声来试。" |

### 配额

- 设问句全稿 ≤2 处，标题 ≤1 处。自问自答算一处。
- 标题零感叹号。正文感叹号 ≤2 个。
- 对仗同句式 ≤2 处。脚本 B8 数感叹号，B9 数设问，B2 抓对仗与骈偶。

## 五规则的协同顺序

一段文本同时中多病时，按此顺序手术：

1. **先拆无灵主语**，找到"谁在做"。主语一明确，句子骨架就正了。
2. **祈使句改陈述 / 判断**，去掉口号腔。不要改成设问。
3. **拆逗号链**，长句切短，句号果断。
4. **清修辞三件套**：删关联词、删设问、删感叹号、拆骈偶。剩下的话应该句句直陈。
5. **最后过简洁关**：朗读一遍，删掉所有删了不伤句子的字。

示例（同一句的五步）：

> 原句：先做一个能用的东西。（祈使句）
> 第一步（拆无灵主语）：先做一个你自己能当场跑起来的东西。（主语"你"浮现）
> 第二步（改判断）：评委要的是能当场跑起来的东西。
> 第三步（拆逗号链，备用）：评委要的不是完美的设想，而是一个你能当场跑起来、经得起追问的东西。（三逗号，要拆）
> 第四步（清关联词）：评委要看的是能当场跑起来的东西。设想再完美，跑不动就停在这一步。
> 第五步（简洁关）：评委只看跑不跑得动。设想再好，也停在这一步。
