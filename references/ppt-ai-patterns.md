# PPT 专属 AI 模式库（A1–A4 + B1–B9 + D 类人工检查单）

通用中文 AI 模式（官方腔、黑话、四字成语串等）见 qu-aiwei-zh 的 `references/zh-patterns.md`。本文件只收 **PPT 场景特有**的模式。扫描脚本 `scripts/scan_ppt_ai.py` 按此编号扣分。

## A 类：词面模式（脚本可自动命中）

### A1 英文装饰标签

中文版式元素上挂英文小标签：`Statement 01`、`Reason 01`、`Evidence First`、`Build, Not Buy`、`Pitfalls · 06`、`Quota Split`、`TAKEAWAYS`、`END OF FIELD NOTE`。

- 判定：≥5 个即高危。均匀分配是机器指纹。只保留 1–2 个签名感的（Field Note、MANIFESTO）。
- 扣分：-3/个，封顶 -12。

### A2 拆字排版

大数字与单位拆成两个形状："300 / 万+"、"2700 / +"、"35 / 岁"、"3 / 层"。

- 判定：>2 处即模板化。只保留 1–2 个重点数字。
- 扣分：-2/个，封顶 -6。

### A3 空词、万能动词与套话

分七组。命中即 -2/个，封顶 -12。前两组是传统空词，后五组是最新的高频 AI 套话。

| 组 | 词例 |
|---|---|
| 空词 | 赋能、助力、彰显、夯实、锚定、聚焦、统筹推进、提质增效、蝶变、跃升、至关重要、全方位、多层次、一站式、闭环 |
| 程度副词通胀 | 极大地、显著地、充分地、深刻地、不可或缺、举足轻重、发挥着重要、日新月异、层出不穷、雨后春笋 |
| 万能动词 | 进行分析、加以、予以、旨在、致力于、着眼于、着力于 |
| 开篇套话 | 随着……的发展 / 推进 / 深入（正则命中）、在当今、众所周知、不可否认、古往今来、从古至今、大背景下 |
| 排比三连与对仗 | 有温度、有深度、有高度、机遇与挑战、传承与创新、注入、新活力、新篇章、新台阶、新大门、加速键、加速度 |
| 陈词套话 | 明灯、指明方向、保驾护航、添砖加瓦、基石、双刃剑、催化剂、助推器、纽带、桥梁、沃土、春风化雨、润物细无声、应运而生、水到渠成 |
| 升华体与翻译腔 | 综上所述、未来可期、拭目以待、共创美好、携手共进、新征程、不负韶华、星辰大海、奔赴山海、贡献力量、被广泛应用、在一定程度上、相对而言、总的来说、伴随着、不断深入 |

说明：词表会持续补充。原则是"删掉不伤句子"——一个词删掉以后句子意思不变，它就是套话。

### A4 AI 高频连接词与关联词

此外、与此同时、综上所述、由此可见、值得一提的是、不难发现、换言之、一方面 / 另一方面、总而言之、不仅、更是、既、又、与其、不如、说到底、本质上、关键在于。

- 扣分：-1/个，封顶 -8。
- "不是 A，而是 B"等对比关联词单算，见 B2。全稿合计 ≤2 处，见句法规则二。

## B 类：结构模式（脚本启发式命中 + 人工确认）

### B1 数字框架成瘾

所有内容被装进整数分点：四个阶段、三个理由、六件事、五个动作、三层方法论、12 个方向、03 Rules。目录导航项全是"数字短语"。

- 判定：数字标语全文 ≥8 处即高危。
- 扣分：-3/处，封顶 -15。
- 改法：标题去掉数量预告（"课堂给不了的三样东西"→ 直接说是什么）。清单砍数量（12→8），每项配具体例子。

### B2 对仗翻转句与骈文对偶（句法规则二、五）

三类同型句式，都是 AI 的套路：

1. **"不是 A，（而）是 B"翻转句**。它曾是去味工具，现在本身成了新模板，全稿 ≤2 处（句法规则二）。"先 X，再 Y"、"A 比 B 更…"同批处理。
2. **骈偶整句**。相邻两句字数相等或接近（差 ≤2 字）、词性相对："字斟句酌，反复推敲""始于兴趣，成于坚持""成本更低，速度更快"。对仗的工整以信息密度为代价。
3. **排比三连**。"有温度、有深度、有高度""成本更低、速度更快、体验更好"。

- 判定：任一句式同型 ≥3 处即高危。"先X再Y" ≥2 处删到 ≤2。
- 扣分：-3/处，封顶 -12。
- 改法：翻转句改直接陈述（"淘汰人的不是创意不够好，而是报名表填错了" → "创意不够好，很少淘汰人。报名表填错，直接出局。"）。骈偶拆成长短不齐的两句，信息拉开。排比三连只留最有信息的一条，其余删。

### B3 祈使句标题（句法规则一）

动词开头的口号式标题。全稿配额 ≤1 处，留给结尾。

- 扣分：-4/处，超出配额部分每处 -2。

### B4 无灵主语（句法规则三）

抽象名词发人类动作："规则淘汰人""比赛逼着你""报名会给你一个进度条""完美主义是敌人"。

- 判定：全文 ≤2 处（谚语式签名句）。超出每处 -3。
- 常见抽象主语词表：规则、比赛、时间、完美主义、报名、进度条、课堂、简历、舞台、评委席。

### B5 自我重复（最强指标）

一字不差的整句在 ≥2 页出现；或同句式 / 同比喻只改数字复用（"胜过十页……"vs"胜过三十页……"）；或同一关键词（如"30 份""当场"）≥3 页复读。

- 判定：命中任何一类即最高优先级，扣 -10/组。
- 说明：人类编辑不可能在几十页里留下这些。这是"机器生成 + 零人工校对"的铁证。

### B6 Manifesto 式结尾

结尾页"宣言金句 + TAKEAWAYS 总结陈词 + 结束标记（→ 完 / END OF…）"模板三件套。

- 扣分：-10/页。
- 改法：删总结陈词。结尾改一句戛然而止的话（"如果只记一件事：先报名，再做好。"）。

### B7 逗号链长句（句法规则四）

一句（两个句号之间）里 ≥3 个逗号。AI 写中文一逗到底：分句四五个一串，该断不断。开头常挂一串状语（"随着……，在……下，……"）。

- 判定：正文每句 -3，封顶 -10。标题里出现单独 -2。标题本该更短。
- 改法：按意思切短句，一个分句一个句号。状语能删就删。详见 `references/syntax-five-rules.md` 规则四。

### B8 感叹号滥用（句法规则五）

标题带"！"，或正文一段塞两个以上感叹号。AI 用感叹号代替说服力，用语气替读者激动。真人做的 PPT 标题几乎零感叹号。

- 判定：标题出现 -4/个（标题本该零感叹号）；正文 -2/个，封顶 -8。
- 改法：删感叹号，句子改陈述。删完发现句子没了力气，说明原句本来就空。"这改变了整个赛道的格局！" → "赛道的评判标准换了。去年的打法今年不灵了。"

### B9 设问句滥用（句法规则五）

以问号收尾的标题，或自问自答段。设问用疑问句式掩盖没有立场，问完不给答案或给万金油答案。PPT 是拿来扫的，判断直接给。

- 判定：标题设问 -3/个（全稿标题配额 ≤1）；正文设问 -2/个，封顶 -6。
- 改法：改成陈述或判断。"什么是好的创意？" → "好创意的标准只有一个：能落地。"自问自答只留答案："时间从哪来？从晚上和周末来。" → "时间从晚上和周末里抠。"

## C 类：页面级诊断（脚本给页面角色，人工判定）

| 页面角色 | 病灶 | 处置 |
|---|---|---|
| 封面 | 祈使口号 + 破折号引金句 | 留 1 个签名句（陈述或判断），其余改直陈 |
| 目录 | B1 数字导航 + "把这份指南拆成 N 个部分" | 导航改信息短语，去掉数量预告 |
| 章节页 | 对仗副题 + 大数字模板 + 同型导航项 | 副题改判断句。挑一个章节页换版式 |
| 内容页（对比 / 流程 / 时间轴） | AI 味最淡 | 重点补具体案例，不动骨架 |
| 金句页（Statement / Manifesto） | AI 味最重：英文标签 + 居中大字 + 两段阐释 | 删，或改成有主语有细节的判断段 |
| 数据页 | 拆字排版 + 数据并列不讲故事 | 选一个数字讲透，其余合并。加官方出处 |
| 结尾页 | B6 模板三件套 | 见 B6 |

## D 类：结构信号（人工检查单，脚本查不出）

这些比任何词汇都准。换词解决不了，得动结构。**命中 ≥3 条，整稿按结构重排**。

1. 每段长度惊人地一致，像切好的豆腐块。真人写作必然有长有短。
2. 几乎每段都以连接词开头（然而 / 因此 / 首先），一段都没漏。
3. 每个观点后面必跟一句解释，句式工整得像在做填空题。
4. 必有一段"总结 + 展望"，且展望部分零信息量。
5. 小标题过度工整，字数都对仗，结构都平行。
6. 全文没有一个具体的人名、地名、时间、数字。全是"某""一些""相关"。
7. 不承认例外、反例和灰色地带，永远滴水不漏、四平八稳。
8. 该用"了、着、过"的地方，全换成书面语动词。时态和语气被磨平。
9. 例子永远是"比如张三""某家企业"这类占位货，没有一个有细节。

## 改写时的三个"不许"

1. 不许为去 AI 味删数据、政策名、时间节点。只改包裹句式。
2. 不许替用户编造真实案例。建议补经历处必须提醒"无案例则标注转述来源"。
3. 不许增加字数。PPT 有可读性预算，去 AI 味主要靠删和换。
