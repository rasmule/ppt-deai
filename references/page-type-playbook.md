# 页面类型改写手册（Page-Type Playbook）

每类页面给出：角色特征 → 病灶 Top3 → 改法套路 → Before/After。所有示例取自一份真实的 AI 生成 PPT（22 页校园竞赛指南），具有代表性。

---

## 1. 封面页

**病灶 Top3**：祈使口号式主标题；破折号引出金句副题；日期+英文小字堆装饰。

**改法**：主标题留一个签名句（陈述或判断），副题说清"这是什么、给谁看"。

- Before：把想法 / 做成 / 作品 ——「两条通往同一个目标的路径——把课本里学过的东西，变成能站上台、能被验证的作品。」
- After：想法和作品之间 / 隔着几百个小时 ——「一份写给新生的双赛入门：比的是什么、怎么报名、第一版要做成什么样。」

## 2. 目录页

**病灶 Top3**：导航项全是"数字短语"（三个理由/五个动作/12 个方向）；「把这份指南，拆成四个阶段」式元叙述。

**改法**：导航改信息短语（去掉数字）；删元叙述，或换成一句使用说明。

- Before：01 为什么参赛 / 02 选对赛道与规则 / 03 从想法到作品 / 04 冲上台与收尾（副题全是"大学里最贵的一门课，以及课堂给不了的三样东西"式对仗）
- After：导航改「凭什么参赛 / 两条赛道怎么选 / 从点子到原型 / 报名之后的事」；底部说明改「按顺序看，或者直接翻到你急的那页。」

## 3. 章节页（STAGE 01–04）

**病灶 Top3**：大数字 84pt + 40pt 标题 + 13pt 副题的统一模板；副题必有一句对仗翻转；底部导航项同型。

**改法**：副题改陈述判断句；四个章节页挑一个换版式（如换成时间/路线示意），打破机械节奏。

- Before：02 选对赛道与规则 ——「两条赛道的评判标准完全不同，而规则比创意更早淘汰人。」
- After：02 选对赛道与规则 ——「创新大赛和挑战杯看的不是一回事，报名规则也不一样。这一章先把它们分清楚。」（保留"规则比创意更早淘汰人"作全稿唯一谚语式签名句时，放内容页首句，别放章节页）

## 4. 内容页：对比/流程/时间轴

**特征**：AI 味最淡的页面——信息具体、可验证。**不要动骨架**，重点补具体性。

**改法**：
- 对比页：每条差异后补一个"所以呢"（对备赛意味着什么）。
- 流程页：每步补一个可验证的数字或例子（"做够 30 份访谈"→"30 份起，少于这个数，评委一问细节就露"）。
- 时间轴：史实保留；把并列的四个节点讲出因果（"1989 年大挑先办起来，十年后小挑加入，从此两个项目交叉轮流"）。
- 长句切短：一句 ≥3 个逗号就拆。Before："随着赛事的不断推进，各高校参与热情持续高涨，报名人数逐年攀升，竞争愈发激烈。" After："赛事一年年办下来，报名的人越来越多。竞争越来越激烈。"

## 5. 金句页（Statement / Manifesto）

**特征**：AI 味最重——英文标签 + 居中两行大字 + 两段阐释，是标准 AI 模板。

**改法**（按优先级）：
1. 整页删（信息已在别处）；
2. 改成有主语有细节的判断段，删英文标签；
3. 保留金句本身，但把阐释段改成具体场景。

- Before：Statement 01 /「大学里最贵的一门课，/ 不在课表上。」/「它没有学分、不点名，也没有标准答案。你要自己报名、自己组队、自己给自己定一个截止日期。但它是大学里少数几个允许你把『学过』变成『做过』、并且有人认真验收结果的地方。」
- After：删"Statement 01"标签；标题改「有门课不在课表上」；正文改「没人点名，没有学分，截止日期得你自己定。但它可能是大学里少数几件『学过』变『做过』、还有人当真验收的事。」

## 6. 数据页

**病灶 Top3**：拆字排版（300/万+）；数字并列不讲关系；无出处。

**改法**：选一个数字讲成故事，其余合并；数据加官方出处（文号/发布会名）——有出处反而更像真人做的功课。

- Before：四个大数字并列（2700+ 高校 / 300 万+ 学生 / 40 万+ 作品 / 5000 席位），页脚一行小字"整理自公开资料"。
- After：留两个数字（"全国 2700 多所高校、300 多万学生参加过往届挑战杯——你校赛的对手，比想象中多"），页脚标「来源：第十九届挑战杯新闻通气会（2025.11）」。

## 7. 结尾页

**病灶 Top3**：TAKEAWAYS 03 RULES 总结陈词；「→ 完 / END OF FIELD NOTE」结束标记；祈使口号收尾（"去报名。然后做完。"）。

**改法**：删总结陈词与结束标记；收在一句戛然而止的话上。全稿唯一的祈使句配额可以花在这里。

- Before：TAKEAWAYS / 03 RULES /「01 先分清楚跑哪条赛道…02 先核对规则，再打磨创意…03 先做出来，再做到好…」/「→ 完 · END OF FIELD NOTE」
- After：「如果只记一件事：先报名，再做好。」（一条就够；想留行动句，把"去报名。然后做完。"改成「报名表十分钟填完。难的是之后那几个月。」）

## 通用手术顺序（每页都走一遍）

1. 数祈使句标题 → 超配额的改陈述/判断；
2. 找无灵主语 → 换成"谁 + 做了什么"；
3. 拆逗号链 → 一句 ≥3 个逗号就切成短句，句号果断；
4. 清修辞三件套 → 删感叹号（标题清零）、设问改直陈、拆对仗骈偶；
5. 删关联词 → "不是A而是B""不仅…更是"等全稿合计 ≤2 处，能直接陈述就别绕；
6. 找对仗翻转与数字框架 → 拆；
7. 过一遍 D 类结构信号检查单（`ppt-ai-patterns.md`）→ 命中 ≥3 条，动结构，别只换词；
8. 英文标签、拆字排版、金句密度过一遍配额；
9. 补一个私有细节 → 具体的时间、地点、小事。这是 AI 编不出来的一步；
10. 朗读一遍 → 删掉所有删了不伤句子的字。像念口号的地方，就是没改干净的地方。
