# ppt-deai：PPT 文本去 AI 味技能

三A大作，AI编写，AI上传，AI更新。把 AI 生成的 PPT 文案改成像真人做的。词库、句法规则、结构信号三层手术，配一个可直接运行的扫描脚本。

## 它能治什么

AI 写的 PPT 有一股机器味，来自三个地方：

1. **词**。套话浓度高："赋能""至关重要""随着……的不断发展"。
2. **句**。一逗到底，一句塞四五个分句。抽象主语发人类动作："规则淘汰人"。设问、感叹、对仗全靠演技。
3. **结构**。每页一个样，不敢详略失衡。

这个技能按这三层逐个手术。

## 核心规则

五大句法规则（完整版见 `references/syntax-five-rules.md`）：

1. **减少祈使句**。口号式命令是 PPT 最大的 AI 破绽。改陈述句、判断句。全稿 ≤1 处，留给结尾。
2. **少用"不是 A，而是 B"等关联词**。它曾是去味工具，现在本身成了新的 AI 模板。判断能直接陈述就别绕。全稿 ≤2 处。
3. **少用无灵主语**。"规则淘汰人"换成"谁 + 做了什么"。谚语式签名句全稿留 1–2 处。
4. **拆逗号链**。AI 写中文一逗到底。标题最多 1 个逗号，正文一句最多 2 个。超过就拆。
5. **少设问、少感叹、减骈偶**。PPT 是拿来扫的，判断直接给。设问全稿 ≤2 处，标题零感叹号，对仗同句式 ≤2 处。

用户逐轮点名、配额一路收紧时进**严格模式**，附加规则六至十一（完整版见 `references/strict-mode-rules.md`）：零比喻、语域降级（替换词语域不得高于原词）、功能词极简（只/就/才/也清零，"是"留 ≤3 处强调框）、指示词清零（这/那/各有各的/今天/从此）、作者话否定词清零（没/不是，引文豁免）、双行标题配平（两侧字数差 ≤2，只挪字不加字）。

## 使用方式

**方式一：作为 Agent 技能加载**

把整个文件夹放进技能目录：

- WorkBuddy：`~/.workbuddy/skills/ppt-deai/`
- Claude Code：`~/.claude/skills/ppt-deai/`

之后对 AI 说"给这份 PPT 去 AI 味"，技能自动加载，按五步工作流执行：提取全文 → 扫描定位 → 按页面类型改写 → 逐页交付 Before→After → 复检闭环。

**方式二：单独跑扫描脚本**

```bash
python3 scripts/scan_ppt_ai.py 提取的文本.txt          # Markdown 报告
python3 scripts/scan_ppt_ai.py 提取的文本.txt --json   # JSON 输出
python3 scripts/scan_ppt_ai.py 提取的文本.txt --strict # 严格模式：追加 C1–C5 实战配额
```

输入格式：每页一行，行首 `P<页码>\t`，页内多个形状用 `\t` 分隔。

```
P1	把想法	做成	作品	—— 两条通往同一个目标的路径
P2	目录 · 全文导航	02 / 22
```

脚本输出 0–100 的"人话分"和按扣分排序的问题清单，覆盖：英文装饰标签、拆字排版、空词套话（约 75 词七组）、AI 连接词、数字框架、对仗翻转与骈偶、祈使句标题、无灵主语、自我重复、Manifesto 结尾、逗号链长句、感叹号滥用、设问句滥用。加 `--strict` 再追加五类实战配额：比喻词（C1）、功能词只/就/才/也（C2）、指示与时空指示词（C3）、作者话否定词没/不是（C4）、双行标题字数失衡（C5），并给出「是」的总计数供人工核对强调框配额。

## 依赖

- Python 3.6+，脚本只用标准库
- 完整改写流程需要一个能读取 PPT 文本的工具（WorkBuddy 用本地 Office 编辑技能）
